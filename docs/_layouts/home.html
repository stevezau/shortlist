Private recommendation rows for every Plex user

Shortlist is a free, open-source, self-hosted tool that gives each person on your Plex server their own rows (Picked for You, Because you watched, seasonal picks, the titles they asked for), built from what they watched and hidden from everyone else.

{%- comment -%} Both captures come from docs/images/two-account.webp: one fake-Plex server, each Home read with that account's own token (tests/e2e/test_marketing_assets.py). The hero crops keep each person's first row and the "Not on this Home" footer, and end after the fourth poster with the card's own right edge spliced on, so no poster or title is cut; the -sm crops end after the third so the posters stay readable on a phone. Corners outside each card are transparent, so the two Homes sit straight on the page in either theme. {%- endcomment -%}

One file, one container. Save it as docker-compose.yml, run docker compose up -d, then open http://your-host:5959. The setup wizard connects Plex and builds the first rows in about ten minutes.

Add SHORTLIST_DRY_RUN=1 to see every change it would make while writing nothing to Plex. Other ways to install are in the install guide.

How it stays private

Plex can’t share a collection with one person. It can hide things by label. So Shortlist labels each row, tells every other account to hide that label, and only then puts the row on Home.

What it writes to your server, and how to undo it

Creates

  • One Plex collection per row, labelled shortlist_<person> so it can always tell its own from yours.
  • One hide entry, label!=shortlist_<person>, merged into every other account’s sharing filter.
  • Home and Recommended placement for its own rows, after the hide entries exist.

Never touches

  • Collections it didn’t make. Kometa, Agregarr and the rest keep their items, names and artwork.
  • Your own sharing-filter entries. It reads the filter, adds its line, and leaves the rest exactly as written.
  • The server owner’s account, which Plex can’t restrict, and managed users’ parental-control profiles.

Uninstall restores

  • Every sharing filter, from a snapshot taken before Shortlist’s first change to it.
  • A preview first. The in-app uninstall shows the restores and the collection deletes, then names any account it couldn’t restore.
  • Run it before removing the container. Deleting the container alone leaves Plex as it is.

One exception to “never touches”: placing rows on the Recommended shelf can move other shelves, keeping their order relative to each other.
