Every Plex user gets their own recommendations

Shortlist looks at what each person on your server has watched, then builds them a “Picked for You” row on their Plex home screen that only they can see. It refreshes overnight.

Get started View source

One Docker container No AI key needed Puts your Plex back if you remove it

The problem

Plex shows everyone the same rows

Everyone on your server opens Plex to a big library and no idea what to put on. The rows Plex builds are the same for every account and lean on its own streaming catalogue, so they don't know your sister has watched every heist film you own and your dad hasn't touched one.

Shortlist gives each person a row of their own instead.

How it works

Four steps, every night

Shortlist runs on a schedule you choose. It works through your users one at a time, so a problem with one person's row never stops anyone else getting theirs.

Read what they watched

Each person's own Plex history. A 20-episode binge counts as one show rather than twenty episodes, so a single series doesn't drown out everything else.

Find things like it

Similar titles from TMDB and Trakt, plus an optional web search for recent ones. Anything you don't already have in your library gets dropped.

Choose and explain

Shortlist picks the best ones and writes the reason for each. This works with no AI at all. Add an AI model and it writes the reasons instead.

Put it on their home screen

The row goes to Plex hidden, everyone else is told not to show it, and only then does it appear. That order is what keeps it private.

Privacy

A row nobody else can see

Plex can't share a collection with one person. What it can do is hide things by label. So Shortlist labels each row, then tells every other account to hide that label. What's left is a row only its owner sees.

The order those steps happen in matters more than the trick itself. Do it the obvious way round and the row is briefly visible to your whole server. Every run goes:

How the hiding works

  1. Clear up firstRemove any row Plex can't hide for that kind of library, before anything else happens.
  2. Send the row hiddenIt exists in Plex, but it isn't on anyone's home screen yet.
  3. Hide it from everyone elseEvery other account is told to hide that row's label. Their existing settings are left exactly as they were.
  4. Now show itOnly now does the row appear, so it is never visible before it is private.

Your settings are saved first

Shortlist copies your sharing settings before it changes anything. Removing it puts them back the way they were.

It adds, it doesn't replace

Shortlist reads what is already in your sharing settings and adds only its own entries. Anything you or another tool set is left alone.

It leaves Kometa alone

Only the collections Shortlist made are ever touched. Anything else on your server is spotted and skipped.

Quick start

Running in about ten minutes

Start the container and open it in a browser. A setup wizard connects your Plex account, asks who should get rows, and builds the first ones.

docker compose 
mkdir shortlist && cd shortlist
curl -fsSLO https://raw.githubusercontent.com/stevezau/shortlist/master/docker-compose.example.yml
mv docker-compose.example.yml docker-compose.yml
docker compose up -d
docker run 
docker run -d --name shortlist \
  -p 5959:5959 \
  -e TZ=Etc/UTC \
  -e PUID=1000 -e PGID=1000 \
  -v /path/to/shortlist/config:/config \
  --restart unless-stopped \
  {{ site.ghcr }}:latest

Want to try it without touching your server? Add -e SHORTLIST_DRY_RUN=1. Shortlist will show you everything it would do and write nothing to Plex until you are happy.

Needs Plex Media Server 1.43.2.10687 or newer, Plex Pass on the admin account, and a free TMDB key. Full requirements →
