Shortlist

A private, personalized “Picked for You” row for every user on your Plex server — built from their own watch history, visible only to them.

{%- comment -%} Children are listed too, not just the top-level sections. Every docs page then carries a link to every other, which is how the deeper pages get crawled at all — the sitemap alone was not enough to get them indexed. So the fix for an eighteen-link column is to SPLIT it, never to drop links: "Plex how-to" is a self-contained set and gets its own column, which balances against Project and Related instead of towering over them. {%- endcomment -%}
