# Surface brief: shortlistapp.dev landing page (docs/index.md + _layouts/home.html)

Scope: landing page refinement, plus the comparison page and the docs/SEO page templates. Visitor mode: Persuade (landing), Read (docs). Platform: web, light and dark.
Audience: a homelab admin arriving from Google, Reddit, Docker Hub, Unraid or an AI answer. Job: decide in one screen whether this is the private per-user rows tool, then install it.
Proof/content: the two-account capture (Sarah vs Mike), real reasons, version + release date, the compose snippet. Constraints: Jekyll on GitHub Pages, allow-listed plugins only, no web fonts added without self-hosting.

## Direction contract

THESIS: Show two people's Homes differing, legibly, before any claim. Refuses the centred-H1-with-one-gold-word + stats band + icon grids landing template.
OWN-WORLD: Existing site palette and type. The hero is two cropped Plex Home captures side by side, each with a visible "Because you watched" reason, on a near-black stage; the rest of the page uses the site's existing light/dark neutrals. Section rhythm: proof, install, how privacy works, what it writes and undoes, maintenance strip, FAQ. No kickers above headings. One install command everywhere via an include.
STORY: "Each person gets their own private row, hidden from everyone else. Here are two of them. Here is the one command." Then they star or install.
FIRST VIEWPORT: H1 with "private" in it, one-sentence definition, the two Homes at readable scale, compose snippet under them as the primary action with a secondary GitHub button showing the star count. The maintenance strip (version, date, PMS requirement, MIT, "nightly on a 40-user server") directly under.
FORM: Refinement of the incumbent world; no concept seed.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
